Consider linear search on an array \(A[1..n]\) for a target value \(x\):

```text
for i = 1 to n:
    if A[i] == x:
        return i
return NOT_FOUND
```

In the worst case, the algorithm must examine every element:

- either \(x\) is not in the array, so all \(n\) elements are checked;
- or \(x\) occurs only at the last position, so again all \(n\) elements are checked.

Each iteration performs a constant amount of work: one comparison and loop overhead. Let that constant cost be \(c\). Then the worst-case running time satisfies

$
T_{\text{worst}}(n) \le c n
$

for all \(n \ge 1\). Therefore, by definition of Big-O,

$
T_{\text{worst}}(n) = O(n).
$

So linear search has worst-case time complexity \(O(n)\).
